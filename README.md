# Магазин сотовых аксессуаров

Интернет-магазин и каталог аксессуаров для смартфонов: чехлы, защитные стёкла, зарядные устройства, павербанки, аудио и держатели. Есть корзина, оформление заказа и защищённая панель администратора. Все цены — в тенге (`₸`).

## Возможности

**Для покупателей**
- Каталог с поиском, фильтром по категориям и цене, сортировкой
- Карточка товара с фото и описанием
- Корзина: изменение количества, удаление, итоговая сумма
- Оформление заказа и страница подтверждения

**Для администратора**
- Вход по логину и паролю (сессия хранится в `sessionStorage`)
- Добавление товара с фото, ценой в тенге и описанием
- Удаление товаров
- Просмотр заказов и смена их статуса

Товары, корзина и заказы сохраняются в `localStorage` и не пропадают при перезагрузке страницы. Интерфейс адаптирован под смартфоны и ПК.

## Стек

- [React 18](https://react.dev/) + [Vite 5](https://vitejs.dev/)
- [Tailwind CSS 3](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — иконки

## Запуск

Нужен Node.js 18+.

```bash
npm install
```

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
```

```bash
npm run preview
```

## Панель администратора

Откройте раздел «Админ» в шапке сайта.

| Логин   | Пароль     |
|---------|------------|
| `admin` | `admin123` |

Учётные данные задаются в [src/hooks/useShop.js](src/hooks/useShop.js). Это демонстрационная клиентская авторизация — для реального магазина нужен сервер с проверкой прав.

## Структура проекта

```
src/
├── App.jsx              # Навигация между страницами
├── main.jsx             # Точка входа
├── index.css            # Tailwind
├── components/
│   ├── Header.jsx       # Шапка, поиск, мобильное меню
│   ├── Catalog.jsx      # Каталог с фильтрами
│   ├── ProductPage.jsx  # Карточка товара
│   ├── CartPage.jsx     # Корзина
│   ├── CheckoutPage.jsx # Оформление заказа
│   ├── SuccessPage.jsx  # Заказ оформлен
│   └── AdminPage.jsx    # Вход и панель администратора
├── hooks/
│   └── useShop.js       # Состояние магазина: товары, корзина, заказы, авторизация
├── lib/
│   ├── storage.js       # Работа с localStorage / sessionStorage
│   └── format.js        # Форматирование цен в тенге
└── data/
    └── seed.js          # Стартовый набор товаров
```

## Сброс данных

Чтобы вернуть стартовый каталог, очистите в DevTools ключи `localStorage`: `qg_products`, `qg_cart`, `qg_orders`.
