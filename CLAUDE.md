# CLAUDE.md - Магазин сотовых аксессуаров

## О проекте
Интернет-магазин и каталог сотовых аксессуаров с корзиной и защищенной панелью администратора.

## Стек
- React / Vite
- Tailwind CSS для стилизации
- Lucide React для иконок

## Финансовые требования
- Все цены в каталоге, корзине и админке указывать строго в национальной валюте Казахстана — тенге (символ `₸` или подписано `тнг`). Формат отображения цен: например, `4 990 ₸`.

## Безопасность и админка
- Панель администратора должна быть защищена простой авторизацией (вход по логину и паролю, например, по умолчанию `admin` / `admin123`, с сохранением сессии в sessionStorage/localStorage).
- Без ввода правильного пароля посторонний пользователь не должен иметь доступ к добавлению или удалению товаров.

## Соглашения
- Чистый, адаптивный интерфейс (смартфоны + ПК).
- Данные товаров и заказов сохранять в localStorage, чтобы они не пропадали при перезагрузке.

## Красные линии
- Создавай полностью рабочие компоненты без заглушек.
- Панель администратора должна позволять добавлять новый товар с фото, ценой в тенге и описанием.
